Livefy Live Bridge Privacy Policy

Single purpose: the Chrome extension connects visible TikTok LIVE operational data to the Livefy workspace selected and controlled by the user.

Information collected

Only when capture is explicitly enabled, the extension processes visible public LIVE comments and usernames, visible product names and prices, visible audience count, TikTok page host/type, extension version, device name and connection health.

Information not collected

Livefy Live Bridge does not access passwords, authentication cookies, payment information, private messages, typed form values, screenshots, microphone, camera, precise location or browsing activity outside the declared TikTok pages.

How information is used

Captured information is transmitted over HTTPS to the user's paired Livefy workspace solely for live operations, analytics and automation configured by that user. It is not sold, used for advertising, transferred for credit decisions or shared for unrelated purposes.

Storage and security

Pairing codes are one-time, expire after 10 minutes and are stored only as cryptographic hashes. Device credentials are stored as hashes on the server and can be revoked from Livefy. The extension queues unsent events locally during temporary connection loss and retries after connectivity returns.

User control and deletion

The user must accept an in-product disclosure before pairing. Capture can be paused at any time in the extension popup. A device can be disconnected locally or revoked in Livefy. Workspace data can be deleted by an authorized workspace member.

Limited Use

Use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Human access is limited to user-requested support, security, legal obligations or appropriately aggregated internal operations.

Contact

Privacy questions and deletion requests can be submitted through the support contact associated with the Livefy Chrome Web Store listing.
