# UI Patterns

- Overview answers health first, commerce second, and recent causality third.
- LIVE Control separates primary operator commands from dangerous runtime termination.
- Tables are used for comparable product data; selection details belong in an inspector.
- Automation explains current strategy, queue, next action, and recent decisions in plain language.
- Rules are expressed as When / If / Then blocks rather than JSON.
- Empty states explain what will appear and, when appropriate, the next recovery action.
- Errors state the failure, affected subsystem, and corrective action.
- Loading skeletons match final geometry. Buttons use inline progress for local operations.
